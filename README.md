# 🏫 مدارسي (Madarisi) - نظام إدارة المدرسة المتكامل

تطبيق ويب حديث ومتطور بالكامل لإدارة شؤون المدارس الابتدائية، مصمم بواجهة مستخدم جذابة تدعم اللغة العربية بالكامل (RTL) مع تأثيرات بصرية عصرية وتكامل ذكي لحفظ وقراءة البيانات محلياً وصنع تقارير بالذكاء الاصطناعي.

---

## ✨ المميزات الرئيسية للتطبيق خارج البرنامج

- **💻 واجهة مستخدم زجاجية (Glassmorphism):** تضفي مظهراً فائق العصرية والجاذبية، خصوصاً في البطاقات المعلوماتية والبيانات الموسعة للمعلمين.
- **💾 حفظ واسترجاع البيانات محلياً (Offline Storage):** مجهز بنظام يعتمد على `localStorage` لحفظ بيانات الطلاب والمعلمين وتقاريرهم حتى لا تفقد مدخلاتك بمجرد إعادة تحميل الصفحة. يمكنك استخدام البرنامج كأداة تشغيل حقيقية بدون الحاجة لقواعد بيانات معقدة!
- **🤖 التقارير الذكية (AI Report Generator):** متصل بمحرك لغة جوجل المتطور (Gemini API) لتحليل مستويات الطلاب ونقاط قوتهم وتوليد تقارير تربوية جاهزة في ثوانٍ.
- **📊 لوحة معلومات تفاعلية ومتحركة:** تعرض إحصائيات متغيرة ودقيقة لعدد الطلاب والمعلمين والأقسام مع مخططات بيانية تفاعلية ممتازة لتوزيع المستويات ونسبة الغيابات الأسبوعية.
- **📱 متجاوب بالكامل (Mobile-First responsive design):** يعمل بكفاءة بالغة على كافة مقاسات الشاشات والهواتف الذكية والأجهزة اللوحية.

## 🚀 كيفية استخدام وتشغيل التطبيق على حاسوبك الشخصي

لتشغيل التطبيق بشكل مستقل أو للعمل عليه محلياً دون أي شروط، اتبع الخطوات البسيطة التالية:

### 1️⃣ المتطلبات الأساسية
تأكد من تثبيت منصة [Node.js](https://nodejs.org/) على جهازك (يفضل الإصدار 18 فما فوق).

### 2️⃣ التثبيت وإعداد الحزم
قم بفك الضغط عن المجلد المصدر في جهازك، ثم افتح موجّه الأوامر داخل المجلد واكتب:

```bash
npm install
```

### 3️⃣ ضبط إعدادات الذكاء الاصطناعي (اختياري)
لتشغيل ميزة توليد التقارير الذكية باستخدام الذكاء الاصطناعي:
1. قم بنسخ الملف `.env.example` وتسميته بـ `.env`.
2. احصل على مفتاح مجاني لـ **Gemini API** من موقع [Google AI Studio](https://aistudio.google.com/).
3. افتح الملف `.env` وضَعْ المفتاح الخاص بك كالتالي:

```env
GEMINI_API_KEY=صداق_المفتاح_الخاص_بـ_جميني
```

### 4️⃣ بدء تشغيل التطبيق في وضع التطوير
لتجربة التطبيق ورؤية التغييرات فوراً على المتصفح:

```bash
npm run dev
```

التطبيق سيكون متاحاً للتصفح فوراً عبر الرابط: `http://localhost:3000` أو الرابط المعروض في مبوب التيرمينال.

## 📦 بناء ونشر التطبيق للاستخدام الفعلي (Build & Production)

إذا أردت إنشاء نسخة نهائية مدمجة وسريعة جداً ورفعها على الإنترنت ليستخدمها المعلمون والإداريون في مدرستك:

```bash
npm run build
```

بعد انتهاء العملية، سيتم توليد مجلد باسم `dist` يحتوي على ملفات HTML وCSS وJS الثابتة والخفيفة جداً.

### 🌐 خيارات النشر المجانية بنقرة واحدة:

تستطيع رفع محتويات مجلد `dist` عالي السرعة وبشكل مجاني بالكامل على أي من المنصات التالية:
- **Netlify:** فقط قم بسحب وإسقاط مجلد `dist` داخل المنصة وسيعمل موقعك مباشرة على الإنترنت مدى الحياة.
- **Vercel:** من خلال ربط مستودع GitHub الخاص بك ببنقرة واحدة وتحديد مسار المجلد.
- **GitHub Pages:** لنشر التطبيق كموقع ساكن بشكل مباشر على خوادم جيت هاب.

## 🛠️ تفاصيل البنية البرمجية

- **الإطار المصدر:** React 19 + TypeScript.
- **أداة البناء:** Vite (لتوفير سرعة فائقة في التشغيل والبناء).
- **التصميم والتنصيب:** Tailwind CSS (تنسيقات عصرية ومتجاوبة بالكامل).
- **مكتبة الأيقونات:** Lucide React (رموز نظيفة وبسيطة وموحدة).
- **المخططات الإحصائية:** Recharts (لعرض الرسوم البيانية المتغيرة للغيابات والمستويات).
